版本更新说明

呆瓜相机（Android）历史版本变更记录。最新版本：v1.14。

v1.14

  • 拍完直接进相册：拍照、录像保存后不再弹“已保存”提示和预览弹窗，安静落盘
  • 新增「同时保存原素材」开关（「风格」面板里）：
    • 打开后，非「正常」风格拍照会存两张：相机原图（_原图）+ 叠加风格的成品
    • 录像会先保存未加风格的原片，再自动生成一份叠加风格的视频，两份都保留、都有声音
    • 「正常」风格只保存一份，不重复占用空间
    • 开关会记忆；录像原片生成风格版本时可取消，原片不受影响
  • 专业参数面板、场景、变焦等沿用 v1.13
  • 操作手册与版本更新说明同步更新

v1.13

  • 界面整体重排：底部换成一块深色圆角面板，只保留三层核心选择，顶栏只留必要的圆钮，画面更干净
    • 第一层：通栏「录像 / 拍照」分段按钮
    • 第二层：等宽「普通 / 专业 / 傻瓜」模式标签
    • 第三层：一个「风格」入口 + 一个随模式变化的「专业参数 / 场景」入口
    • 相册、切换镜头移到快门左右两侧，顶栏不再拥挤
  • 变焦更好找、更顺滑：
    • 画面右侧新增常驻竖向变焦滑条，上下拖动变焦，顶部实时显示倍数，双击恢复 1 倍
    • 修复双指捏合不跟手：改为按手势增量累乘，捏合与滑条实时同步
    • 变焦范围 1×–10×，按摄像头能力自动限制
  • 从相册读取拍摄参数：傻瓜模式场景列表新增「从相册照片 / 视频读取拍摄参数」
    • 照片读取 EXIF 的 ISO、快门、曝光补偿、白平衡/色温、对焦距离，预填到场景编辑器
    • 视频读取帧率与编码信息中能拿到的参数，读不到的保持自动
    • 确认名称后直接保存为新场景，和内置场景一样使用
  • 专业参数存为场景：专业参数面板新增「存为场景」，把当前这组 ISO / 快门 / 白平衡 / 对焦一键存进傻瓜模式
  • 风格面板：所有风格与「卡通强度」收进一个面板，点选即生效
  • 操作手册与版本更新说明同步更新

v1.12

  • 闪光灯：顶部新增 ⚡ 按钮，循环切换 自动 / 常开 / 常闭，默认自动，选择会记忆
    • 拍照自动闪光、常开每次闪；录像「常开」变成手电筒常亮补光
    • 无闪光灯的摄像头按钮自动变暗并提示
  • 双指变焦：在预览画面捏合 / 张开即可变焦，拍照和录像都生效
    • 右上角显示当前倍数，点一下恢复 1 倍
    • 切换前后摄像头自动回到 1 倍
  • 录像/拍照沿用 v1.11 的普通 / 专业 / 傻瓜模式与场景参数
  • 操作手册与版本更新说明同步更新

v1.11

  • 录像也能选模式和调参数：第二层「普通 / 专业 / 傻瓜」对录像同样生效
    • 录像 · 专业：可手动设置 ISO、快门、曝光补偿、白平衡、对焦，参数实时作用于录制画面
    • 录像 · 傻瓜：25 个场景任选，支持换场景、长按调参、新增自定义场景
    • 录像手动快门最长 1/30 秒，自动限制，避免掉帧
  • 底部操作区按层级重新排列，一眼分清：
    • 第一层：大号分段按钮「录像 / 拍照」
    • 第二层：带「模式」标签的「普通 / 专业 / 傻瓜」
    • 第三层：带「风格」标签的卡通风格栏
  • 录像和拍照各自记忆模式、专业参数与场景选择，互不覆盖
  • 说明文档同步更新

v1.10

  • 操作手册与版本更新说明打包进 APK：顶部新增「说明」按钮，内置两个标签页，完全离线可看
  • 手册内容更新：界面说明加入「说明」入口，版本号同步
  • 小精灵默认关闭、正常风格等逻辑不变

v1.9

  • 小精灵默认关闭：新安装默认不显示小精灵；从旧版本升级时也会自动关闭一次，之后完全尊重用户自己的开关
  • 新增《操作手册》（USER_GUIDE.md）与《版本更新说明》（CHANGELOG.md）
  • 正常 / 卡通等风格逻辑不变

v1.8

  • 底部风格栏最前面新增 正常，并设为默认风格（录像、拍照共用）
  • 正常模式不做任何卡通调色：预览、录像、拍照、相册图片/视频均原样输出（只保留裁剪与镜像）
  • 相册里的 mp4 视频在正常模式下直接原样保存，不再重新编码
  • 正常模式下拍照直接保存相机原图，不经过 GPU 管线，成功率更高
  • 正常模式下「风格强度」滑块自动置灰

v1.7

  • 包名改为 com.qoder.daiguacamera（与旧版本不兼容，需卸载旧版后重装）
  • 场景参数可编辑：内置场景支持调整、保存、恢复默认
  • 支持新增自定义场景，配好参数后与内置场景一样使用

v1.6

  • 应用更名为「呆瓜相机」
  • 修复「处理照片卡通化没成功」：手动曝光参数被拒时自动回退、渲染失败时降级重试、小精灵层异常隔离、Android 9 及以下补存储权限、拍照卡死时保存预览画面兜底

v1.5

  • 拍照新增三种模式：普通 / 专业 / 傻瓜
  • 傻瓜模式内置 25 个场景预设（日出、日落、星空、夜景、烟花、雪景、人像、美食等），自动匹配曝光与白平衡
  • 新增小精灵总开关，可决定相机、拍照、相册处理时是否出现小精灵

v1.4

  • 新增相册处理：图片与视频都能卡通化
  • 图片保存为 JPEG，最长边 1600；视频重编码为 mp4（最长边 1280）并保留原音轨

v1.3

  • 小精灵多样化：8 个种族、6 种性格，各自偏好不同的落脚点与反应
  • 小精灵会随手机晃动、触摸抚摸和敲击做出不同反应

v1.2

  • 新增随机小精灵：按画面内容自动选位，支持触摸互动

v1.1

  • 大幅增强卡通化效果：半分辨率双边平滑 + YIQ 色阶量化 + Sobel 描边

v1.0

  • 首个版本：Camera2 + OpenGL ES 实时卡通滤镜、6 种风格、视频录制
