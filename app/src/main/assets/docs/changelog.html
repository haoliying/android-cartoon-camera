版本更新说明

呆瓜相机（Android）历史版本变更记录。最新版本：v1.22。

v1.22

  • 傻瓜模式新增 2 个自然场景（内置场景 33 → 35 个）：
    • 树叶：ISO 100、1/200 秒、+0.3 EV、5600K、微距对焦，近摄叶脉清晰，逆光下叶片更通透
    • 树：ISO 100、1/320 秒、+0.3 EV、5800K、无穷远对焦，收住整棵树冠细节，绿色不发黄
  • 操作手册与版本更新说明同步更新

v1.21

  • 新增构图助手（顶部「构图」按钮，点击开关）：
    • 取景网格：三分法 / 中心 / 对角线三种，长按「构图」切换
    • 主体框与人脸框：自动找出画面主体；相机支持人脸检测时，人脸框会单独标出
    • 地平线检测：识别天空与地面，画出地平线；倾斜超过约 2° 提示转正
    • 构图建议：主体太小 / 太满、头顶贴边、偏离三分线（带左右方向箭头）、背景边缘杂乱、对称没摆正、引导线用得好等
    • 逆光识别：背景明显亮于主体时提示逆光，可直接点「套用逆光」切到逆光场景
    • 自动校平（可选）：拍照时按测得倾角自动旋转裁切，照片尺寸不变、四角不露黑边
    • 分析全部在本机完成，相机不出帧时自动跳过，不影响拍摄
  • 操作手册与版本更新说明同步更新

v1.20

  • 傻瓜模式新增 6 个常用场景（内置场景 27 → 33 个）：
    • 阴天：自动曝光 +0.5 EV、白平衡 6800K，平光下不发灰
    • 室内：自动曝光 +0.3 EV、白平衡 3800K，压住偏黄并小幅提亮
    • 夜景人像：ISO 1600、1/30 秒、4300K，人物不易糊、脸不发黑
    • 舞台：ISO 1600、1/160 秒、4000K，抓得住台上动作
    • 宠物：ISO 400、1/320 秒、5600K，冻结毛发与动作
    • 文档：ISO 100、1/200 秒、微距对焦，拍平文字与表格
    • 阴天 / 室内用「自动曝光 + 曝光补偿」，适应不同机型的实际亮度；其余为完整手动参数，都可以长按场景改
  • 操作手册与版本更新说明同步更新

v1.19

  • 拍照新增「底片」模式（第一层选「拍照」后可见）：
    • 实时预览就是负片效果，拍下来的文件也是底片，文件名带 Daigua_NEG_
    • 点右侧「底片参数」可调：反转强度、橙色底罩、对比度、饱和度、色相、颗粒、亮度；饱和调到 0 就是黑白底片
    • 参数记在本机，下次打开沿用；底片只在拍照模式提供，录像下自动隐藏
  • 相册新增调色编辑器，照片和视频都能用：
    • 内置模式：原图、自动优化、鲜明、柔和、黑白、复古、胶片、冷调、暖调、青橙、底片转成片
    • 可调参数：亮度、对比度、饱和度、色温、色觉 / 色相、色差、暗角、颗粒、底片转成片
    • 照片实时预览（拖动滑块即时更新），视频逐帧重新编码并保留原音轨
    • 打开 Daigua_NEG_ 底片时会自动选中「底片转成片」，反相并去掉橙色底罩
    • 调好的参数可以「存为模式」，像傻瓜模式的场景一样保存、复用；自定义模式长按可删除
    • 原来的「相册卡通化」保留为编辑器里的「卡通化（当前风格）」，按当前风格、强度和小精灵处理
  • 操作手册与版本更新说明同步更新

v1.18

  • 修复广角镜头下闪光灯被判为“没有闪光灯”：超广角镜头本身通常不报闪光灯能力，现在改按后置主摄判断，闪光灯按钮保持可用（自动 / 常开 / 常闭都能设置）；在广角下点闪光灯会自动切回主摄，切回后再设置
  • 广角镜头的焦距盘改为 0.1×–1×：切到广角后量程是 0.1×（最广）到 1×（与主摄 1× 视野衔接），不再出现广角镜头也被数字变焦到 100× 的情况；点「主摄」切回后恢复 1×–100×
  • 操作手册与版本更新说明同步更新

v1.17

  • 焦距控制盘更跟手：重新分配行程，1×–10× 占了大半圈，轻轻一拖就有明显变化；盘面直接标出处于量程内的 0.5 / 1 / 2 / 3 / 5 / 10 / 30 / 100 等倍数，点数字可以直接跳过去，经过刻度还有轻微震动反馈
  • 广角更容易找到：
    • 支持变焦比例（能到 1× 以下）的机型，盘面会出现 0.5 刻度，向下拖或点 0.5 即可切到广角
    • 部分机型把超广角做成独立摄像头，变焦范围里没有 0.5×；这类机型在焦距盘下方多出一个「广角」按钮，点一下切到超广角，再点「主摄」切回
    • 广角镜头打不开时会自动退回主摄并提示，不会停在黑屏
  • 新图标：呆瓜（条纹西瓜）+ 相机镜头，深色底配珊瑚色光环
  • 操作手册与版本更新说明同步更新

v1.16

  • 傻瓜模式新增两个固定预设，排在最前面：
    • 日常：就是普通拍摄，全自动，拿起就拍（傻瓜模式默认项）
    • 自动场景：自动根据环境亮度和机身动静匹配参数，暗光切夜景、运动切运动模式，其余用普通自动
    • 两者是固定预设，长按只显示说明，不参与参数编辑
  • 焦距控制盘重新设计：改成仿相机镜头环的圆形刻度盘，刻度环 + 高亮进度弧 + 指示点，中间显示倍数；在盘面上上下拖动变焦，向上放大、向下缩小
  • 变焦范围扩展到 0.1×–100×：
    • 支持逻辑多摄的机型通过变焦比例解锁 0.5× 广角
    • 超过设备数码变焦上限的部分用软件中心裁切补足，预览、录像、拍照同步生效
    • 不支持广角的机型最低 1×；控制盘会按设备能力自动收窄下限
  • 控制盘收起成右侧小圆钮、底部面板缩到最下方等交互保持不变
  • 操作手册与版本更新说明同步更新

v1.15

  • 点击预览设置对焦点：轻点画面即在点击位置显示白色对焦圈，并把相机 AF / AE 测光区域移到该点；拖动、捏合不会误触发，对焦圈约 1.5 秒后淡出
  • 焦距改为控制盘：原右侧竖向滑条换成圆形控制盘，按住圆环拖动即可变焦，盘面中间实时显示倍数
    • 量程 1×–100×；设备支持不到时自动停在设备的最大 / 最小值
    • 控制盘可收起成右侧小圆钮，点小圆钮重新展开，把画面让到最大
  • 底部控制区可收起：面板顶部新增收起把手，点一下整块控制区缩到屏幕最下方，只留一条细把手；再点展开。收起状态会记住
  • 双指捏合变焦、切换镜头复位、拍照 / 录像共用变焦逻辑保持不变
  • 操作手册与版本更新说明同步更新

v1.14

  • 拍完直接进相册：拍照、录像保存后不再弹“已保存”提示和预览弹窗，安静落盘

    • 修复双指捏合不跟手：改为按手势增量累乘，捏合与滑条实时同步
