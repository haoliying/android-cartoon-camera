版本更新说明

呆瓜相机（Android）历史版本变更记录。最新版本：v1.10。

v1.10

  • 操作手册与版本更新说明打包进 APK：顶部新增「说明」按钮，内置两个标签页，完全离线可看
  • 手册内容更新：界面说明加入「说明」入口，版本号同步
  • 小精灵默认关闭、正常风格等逻辑不变

v1.9

  • 小精灵默认关闭：新安装默认不显示小精灵；从旧版本升级时也会自动关闭一次，之后完全尊重用户自己的开关
  • 新增《操作手册》（USER_GUIDE.md）与《版本更新说明》（CHANGELOG.md）
  • 正常 / 卡通等风格逻辑不变

v1.8

  • 底部风格栏最前面新增 正常，并设为默认风格（录像、拍照共用）
  • 正常模式不做任何卡通调色：预览、录像、拍照、相册图片/视频均原样输出（只保留裁剪与镜像）
  • 相册里的 mp4 视频在正常模式下直接原样保存，不再重新编码
  • 正常模式下拍照直接保存相机原图，不经过 GPU 管线，成功率更高
  • 正常模式下「风格强度」滑块自动置灰

v1.7

  • 包名改为 com.qoder.daiguacamera（与旧版本不兼容，需卸载旧版后重装）
  • 场景参数可编辑：内置场景支持调整、保存、恢复默认
  • 支持新增自定义场景，配好参数后与内置场景一样使用

v1.6

  • 应用更名为「呆瓜相机」
  • 修复「处理照片卡通化没成功」：手动曝光参数被拒时自动回退、渲染失败时降级重试、小精灵层异常隔离、Android 9 及以下补存储权限、拍照卡死时保存预览画面兜底

v1.5

  • 拍照新增三种模式：普通 / 专业 / 傻瓜
  • 傻瓜模式内置 25 个场景预设（日出、日落、星空、夜景、烟花、雪景、人像、美食等），自动匹配曝光与白平衡
  • 新增小精灵总开关，可决定相机、拍照、相册处理时是否出现小精灵

v1.4

  • 新增相册处理：图片与视频都能卡通化
  • 图片保存为 JPEG，最长边 1600；视频重编码为 mp4（最长边 1280）并保留原音轨

v1.3

  • 小精灵多样化：8 个种族、6 种性格，各自偏好不同的落脚点与反应
  • 小精灵会随手机晃动、触摸抚摸和敲击做出不同反应

v1.2

  • 新增随机小精灵：按画面内容自动选位，支持触摸互动

v1.1

  • 大幅增强卡通化效果：半分辨率双边平滑 + YIQ 色阶量化 + Sobel 描边

v1.0

  • 首个版本：Camera2 + OpenGL ES 实时卡通滤镜、6 种风格、视频录制
