呆瓜相机 · 操作手册

适用版本：v1.10（versionCode 11）
系统要求：Android 7.0 及以上
包名：com.qoder.daiguacamera

1. 安装与首次启动

  1. 安装 daigua-camera-v1.10.apk。如果手机提示“未知来源”，允许当前文件管理器安装即可。
  2. 首次打开会申请 相机 和 麦克风 权限：
    • 相机：必需，否则无法预览和拍摄。
    • 麦克风：录像收音用；拒绝也能录像，但视频没有声音。
  3. Android 9 及以下在第一次保存照片/视频时会再申请一次存储权限，允许后才能写入相册。
  4. 从 v1.6 及更早版本升级（旧包名 com.qoder.cartooncamera）需要先卸载旧版；v1.7 起包名已统一，可直接覆盖安装。

2. 界面一览

顶部

按钮 作用
相册 从系统相册选一张图片或一段视频，用当前风格处理
说明 打开内置的操作手册与版本更新说明（离线可看）
✦ 小精灵开关（默认关闭）
⇄ 前置 / 后置摄像头切换（录像中不可用）

底部

  • 录像 / 拍照：两种拍摄模式，录像中不能切换。
  • 普通 / 专业 / 傻瓜：仅拍照模式显示。
  • 风格栏：正常、卡通、漫画、水彩、素描、像素、霓虹。默认「正常」。
  • 风格强度：0%–100%，只对卡通类风格有效；「正常」下自动置灰。
  • 参数行：专业模式显示参数摘要和「调整」；傻瓜模式显示当前场景和「换场景」。
  • 快门键：录像时是红色圆点，拍照时是白色圆点。

3. 录像

  1. 确认底部选中「录像」。
  2. 点一次快门开始录制，顶部出现红点和计时。
  3. 再点一次快门停止并保存。
  4. 视频保存到相册的 Movies/DaiguaCamera，完成后会提示保存位置。

录像使用当前选中的风格：选「正常」就是相机原始画面；选卡通类风格就是实时卡通画面。

4. 拍照

点「拍照」后，可在三种子模式中选择。

4.1 普通

全自动曝光、自动白平衡、自动对焦，适合随手拍。拍完按当前风格处理并保存到 Pictures/DaiguaCamera。

4.2 专业

点参数行右侧「调整」，可分别设置：

参数 说明
ISO 自动，或 100 / 200 / 400 / 800 / 1600 … 等固定值
快门 自动，或 1/1000s–2s 的固定速度
曝光补偿 -2.0 到 +2.0，仅自动曝光时生效
白平衡 自动，或 2300K–7900K 手动色温
对焦 自动 / 无穷远 / 微距 / 手动
手动焦距 对焦选「手动」时生效，0–10 档，数值越大对得越近

规则：**ISO 和快门都选“自动”**时走自动曝光，只叠加曝光补偿；任意一个选了固定值就切到手动曝光，此时曝光补偿不再生效。

设置会记在本机，下次打开仍然保留。

4.3 傻瓜

内置 25 个场景，按类别大致分为：

  • 风光与夜景：日出、日落、晚霞、月亮、星空、夜景、烟花、灯
  • 自然：大海、瀑布、远山、云、丁达尔、雾、彩虹
  • 天气：雨滴、雨天、长雨丝、雪花、雪天、雪景
  • 人像与静物：人像、逆光、美食、花

点一下即使用，参数行会显示场景名和一句提示。

调整场景

  • 点「换场景」→ 长按任意场景，进入参数编辑。
  • 内置场景：可改参数、可「恢复默认」，不能改名。
  • 自定义场景：可改名、改参数、删除。
  • 点「＋ 新增场景」，填名称和提示、调好参数后保存，就会出现在场景列表里，和内置场景一样使用。
  • 列表里的标记：·自 表示自定义场景，* 表示参数被改过。

场景参数只影响曝光、白平衡、对焦，不改变卡通风格。

5. 风格与强度

风格 特点
正常（默认） 不做任何卡通处理，直接输出相机画面
卡通 平整色块 + 描边，通用卡通感
漫画 更强描边和网点
水彩 柔和色块、轻微颗粒
素描 黑白铅笔线条
像素 像素块化
霓虹 高饱和、发光描边

「正常」模式下，预览、录像、拍照、相册处理都原样输出，只保留画面裁剪和前置镜像；此时风格强度滑块置灰。切回任意卡通风格后，强度立即恢复作用。

6. 小精灵

  • 默认关闭。点顶部 ✦ 打开，再点关闭；按钮变暗表示关闭。
  • 打开后，小精灵会出现在实时预览、录像、拍照和相册处理结果里；关闭后全部不出现。
  • 小精灵会根据画面内容挑平整的位置落脚，随手机晃动、触摸抚摸、敲击做出不同反应。
  • 目前有 8 个种族、6 种性格，每次出现的小精灵不完全一样。

建议：想要干净的照片就保持关闭；想要“呆瓜”一点的效果再打开。

7. 相册处理

  1. 点顶部「相册」，选择一张图片或一段视频。
  2. 按当前的风格、强度和小精灵开关处理，弹窗显示进度，可随时取消。
  3. 完成后自动保存，图片会弹出预览。

处理规则：

  • 图片：最长边 1600，保存为 JPEG 到 Pictures/DaiguaCamera。
  • 视频：最长边 1280，重编码为 mp4 到 Movies/DaiguaCamera，原音轨会保留。
  • 正常 + 小精灵关闭：图片直接复制（超过 1600 会缩到 1600），mp4 视频直接原样复制、不重新编码，速度最快、画质无损。
  • 处理视频会调用硬件编解码，机身发热、耗电属于正常现象。

8. 保存位置

内容 位置
拍照 / 相册图片 Pictures/DaiguaCamera
录像 / 相册视频 Movies/DaiguaCamera

保存成功后会提示「已保存到相册 · …」。在系统相册的「相册」或「文件夹」里也能找到 DaiguaCamera。

9. 常见问题

预览黑屏 / 相机打不开
检查是否授予相机权限；如果其他应用正在占用相机，先关闭它；仍不行时退出重进。

录像没有声音
麦克风权限被拒绝。到系统设置 → 应用 → 呆瓜相机 → 权限，打开麦克风。

保存失败
Android 9 及以下需要存储权限；同时确认手机剩余空间充足。

拍照处理失败
应用会自动降级重试（关闭小精灵、降低分辨率）；如果相机原图始终拿不到，会改为保存当前预览画面并在弹窗中说明原因。

相册视频处理很久
卡通化需要逐帧解码和重编码。只想保留原片时，把风格切到「正常」并关闭小精灵，会直接复制原视频。

换手机后设置没了
风格、专业参数、场景等设置只保存在本机应用私有空间，卸载或换机不会同步。

想要更干净的画面
风格选「正常」、关闭小精灵；需要更强效果时再提高卡通风格强度。
