呆瓜相机 · 操作手册

适用版本：v1.26（versionCode 27）
系统要求：Android 7.0 及以上
包名：com.qoder.daiguacamera

1. 安装与首次启动

  1. 安装 daigua-camera-v1.26.apk。如果手机提示“未知来源”，允许当前文件管理器安装即可。
  2. 首次打开会申请 相机 和 麦克风 权限：
    • 相机：必需，否则无法预览和拍摄。
    • 麦克风：录像收音用；拒绝也能录像，但视频没有声音。
  3. Android 9 及以下在第一次保存照片/视频时会再申请一次存储权限，允许后才能写入相册。
  4. 从 v1.6 及更早版本升级（旧包名 com.qoder.cartooncamera）需要先卸载旧版；v1.7 起包名已统一，可直接覆盖安装。

2. 界面一览

顶部（左侧闪光灯与构图，右侧说明与小精灵，中间留白）

按钮 作用
⚡（左） 闪光灯：自动 / 常开 / 常闭，点一下循环切换，默认自动
构图（左） 构图助手开关，打开后出现网格与构图提示；长按可换网格样式、主体偏好和自动校平
说明（右） 打开内置的操作手册与版本更新说明（离线可看）
✦（右） 小精灵开关（默认关闭）

右侧 · 焦距控制盘

画面右上方是一个圆形焦距控制盘：刻度环 + 高亮进度弧，上下拖动即可变焦（向上放大、向下缩小），盘面中间实时显示倍数。盘面还标着 0.5 / 1 / 2 / 3 / 5 / 10 / 30 / 100 等常用倍数，点数字可以直接跳过去。主摄量程 1×–100×，支持变焦比例的机型可以到 0.5× 一类广角；超过设备数码变焦上限的部分由软件中心裁切补足。部分机型把超广角做成独立镜头，盘面下方会多出一个「广角」小圆钮，点一下切到超广角（此时量程变为 0.1×–1×）、再点「主摄」切回。点圆盘右上角的「›」可把它收起成右侧一个小圆钮（只显示当前倍数），点小圆钮即可重新展开，把画面尽量让出来。

底部（深色圆角面板，从上到下）

  • 收起把手：面板最上方有一条短横线和「收起」字样，点一下整块控制区会缩到屏幕最下方，只留下这条把手，画面可视范围最大；再点一下「展开」恢复。
  • 第一层 · 拍摄方式：通栏分段按钮「录像 / 拍照」。录像中不能切换。
  • 第二层 · 模式：「普通 / 专业 / 傻瓜 / 底片」，等宽标签，录像和拍照各自独立记忆；「底片」只在拍照时出现。
  • 第三层 · 风格与参数：左侧「风格 · 当前风格 ▾」打开风格面板；右侧在专业模式显示「专业参数 · …」，傻瓜模式显示当前场景名，点一下即可调整。
  • 快门行：左「相册」、中快门、右「⇄」切换前后摄像头。
  • 快门键：录像时是红色圆点，拍照时是白色圆点。
  • 预览区：按相机真实画幅在屏幕中间完整显示，左右/上下不足的地方留黑边，不裁切画面，取景框看到的就是成片的范围；轻点设置对焦点（出现白色对焦圈），点在黑边上不会触发对焦；双指捏合 / 张开调整变焦，和右侧控制盘同步。

3. 录像

  1. 确认第一层选中「录像」。
  2. 在第二层选择「普通 / 专业 / 傻瓜」：
    • 普通：全自动曝光、白平衡和对焦，开箱即用。
    • 专业：点右侧「专业参数」，可手动设置 ISO、快门、曝光补偿、白平衡、对焦；录像快门最长 1/30 秒，超过会自动限制，保证画面流畅不掉帧。
    • 傻瓜：38 个场景任选，点场景名切换，和拍照共用同一套场景参数。
    • 「底片」只在拍照模式提供，录像下不显示。
  3. 点一次快门开始录制，顶部出现红点和计时。
  4. 再点一次快门停止。视频会直接保存到相册，不再弹“已保存”提示或预览。
  5. 视频保存到 Movies/DaiguaCamera。录像画幅和取景框一致，录到的范围和预览相同，不会多裁一圈。

同时保存原素材（在「风格」面板里打开）：风格不是「正常」时，录像会先保存一份未加风格的原片（文件名带 _原片），再在后台生成一份叠加风格的版本，两份都带声音、都进相册；生成期间可以点弹窗取消，原片会保留。风格为「正常」时只保存一份。

录像的曝光、白平衡、对焦参数会实时作用在录制画面上；风格仍然来自「风格」面板。选「正常」就是相机原始画面，选卡通类风格就是实时卡通画面。

录像和拍照的模式、专业参数、场景分别记忆，切换拍摄方式不会互相覆盖。场景本身是共用的，在一个模式下调整参数，另一个模式里也会看到。

4. 拍照

点「拍照」后，可在四种模式中选择：普通、专业、傻瓜、底片。

4.1 普通

全自动曝光、自动白平衡、自动对焦，适合随手拍。拍完按当前风格处理并保存到 Pictures/DaiguaCamera。

成片和取景框保持同一个视野，不再额外裁切：取景框里看到的画面会完整出现在照片里，边缘景物不会被切掉。取景框画幅跟随相机的实际拍照尺寸，照片与取景框比例不同时会在四周留黑边（不裁画面）。

4.2 专业

点右侧「专业参数」，可分别设置：

参数 说明
ISO 自动，或 100 / 200 / 400 / 800 / 1600 … 等固定值
快门 自动，或 1/1000s–2s 的固定速度
曝光补偿 -2.0 到 +2.0，仅自动曝光时生效
白平衡 自动，或 2300K–7900K 手动色温
对焦 自动 / 无穷远 / 微距 / 手动
手动焦距 对焦选「手动」时生效，0–10 档，数值越大对得越近

规则：**ISO 和快门都选“自动”**时走自动曝光，只叠加曝光补偿；任意一个选了固定值就切到手动曝光，此时曝光补偿不再生效。

以上参数在录像的「专业」模式里同样可调；录像时快门上限为 1/30 秒。

设置会记在本机，下次打开仍然保留；拍照和录像的专业参数分别保存。

调好后点「存为场景」，给这组参数起个名字，就会保存到傻瓜模式的场景列表里，以后一键复用。

拍照完成后同样直接保存到相册，不再弹预览和“已保存”提示。打开「同时保存原素材」且风格不是「正常」时，会存两张：一张相机原图（文件名带 _原图），一张叠加风格的成品；「正常」风格只存一张。

4.3 傻瓜

内置 38 个场景，最前面两个是固定预设：

  • 日常：就是普通拍摄，全自动，拿起就拍（傻瓜模式的默认项）
  • 自动场景：自动看环境亮度和机身动静，暗光切夜景、运动切运动模式，其余交给普通自动；设备不支持场景模式时等同于普通自动

其余 36 个场景按类别大致分为：

  • 一天里的光线：清晨、中午、傍晚
  • 风光与夜景：日出、日落、晚霞、月亮、星空、夜景、夜景人像、烟花、灯、舞台
  • 自然：大海、瀑布、远山、云、树、阴天、丁达尔、雾、彩虹
  • 天气：雨滴、雨天、长雨丝、雪花、雪天、雪景
  • 人像与静物：人像、逆光、室内、宠物、美食、花、树叶、文档

点一下即使用，参数行会显示场景名和一句提示。

调整场景

  • 点右侧场景名打开场景列表，点一下即使用。
  • 长按任意场景，进入参数编辑；「日常 / 自动场景」是固定预设，长按只显示说明。
  • 内置场景：可改参数、可「恢复默认」，不能改名。
  • 自定义场景：可改名、改参数、删除。
  • 点「＋ 新增场景」，填名称和提示、调好参数后保存，就会出现在场景列表里，和内置场景一样使用。
  • 点「从相册照片 / 视频读取拍摄参数」，选一张照片或一段视频，应用会自动读出 ISO、快门、曝光补偿、白平衡、对焦距离等 EXIF 信息，预填到场景编辑器里，确认名称后保存即可。
    • 照片：读取 EXIF；没有 EXIF 的图片会提示无可读参数。
    • 视频：读取帧率、编码参数里能拿到的 ISO/曝光等；手机视频通常信息较少，读不到的部分保持自动。
  • 列表里的标记：·自 表示自定义场景，·调 表示参数被改过。

场景参数只影响曝光、白平衡、对焦，不改变卡通风格。

4.4 底片

底片模式拍摄的是负片：预览就是反相后的画面，按下快门保存的也是负片文件（文件名 Daigua_NEG_…jpg），之后可以在相册里一键转成正常照片。

点右侧「底片参数」，可调：

参数 说明
反转强度 0%–100%，100% 是完全负片
橙色底罩 模拟彩色负片未曝光区域的橙色，0% 为中性反相
对比度 60%–140%
饱和度 0%–160%，调到 0 就是黑白底片
色相 -40°–+40° 色彩偏移
颗粒 0%–50% 胶片颗粒
亮度 -20–+20

参数会实时作用在预览上，并记在本机，下次进入底片模式沿用。底片模式固定按正常画面反相，不叠加「风格」面板里的卡通风格；风格入口会自动隐藏。

拍完的底片可以在相册里选「底片转成片」：自动反相并中和橙色底罩，再按需要微调。

5. 闪光灯与变焦

5.1 闪光灯

顶部 ⚡ 按钮循环切换 自动 → 常开 → 常闭，默认「自动」，选择会记在本机。

状态 拍照 录像
自动 光线不足时自动闪 不闪（连续录像无法逐帧测光）
常开 每次都闪 变成常亮补光（手电筒）
常闭 完全关闭 完全关闭

说明：

  • 专业模式使用手动曝光（ISO 或快门选了固定值）时，「自动」没有测光依据；需要闪光请选「常开」。
  • 前置摄像头通常没有闪光灯，按钮会变暗，点击会提示不可用。
  • 超广角镜头本身通常也不报闪光灯能力：在广角下闪光灯按钮仍可用，点一下会先切回主摄再应用当前闪光灯设置。
  • 录像「常开」会持续点亮闪光灯，机身发热、耗电增加属于正常现象。

5.2 变焦（焦距控制盘）

两种方式，效果完全一样，拍照和录像都生效：

  1. 右侧焦距控制盘：在盘面上上下拖动即可变焦，向上放大、向下缩小；盘面中间实时显示倍数，0.5×–10× 的行程最长、最好控制。盘面标出的常用倍数可以直接点（例如点 0.5 就是广角、点 2 就是 2×），经过刻度会有轻微震动。点右上角「›」可收起成小圆钮，点小圆钮重新展开。
  2. 双指捏合 / 张开：在预览画面上操作，松手后倍数保持；和控制盘实时同步。

说明：

  • 主摄控制盘量程为 1×–100×；实际下限由设备决定，支持变焦比例的机型可以到 0.5× 广角（盘面会显示 0.5 刻度），不支持的机型最低 1×。
  • 如果机型把超广角做成独立摄像头（变焦范围里没有 0.5×），焦距盘下方会出现「广角」按钮：点一下切到超广角镜头，按钮变成「主摄」；再点切回。广角镜头的控制盘量程是 0.1×–1×（0.1× 最广，1× 与主摄视野衔接），切回主摄后恢复 1×–100×。切换镜头会重新打开相机，画面会短暂停顿，录像中不能切换。
  • 设备数码变焦到顶后，继续放大的部分是软件中心裁切，预览和录像会直接放大，拍照也会按同一比例裁切；倍数越高画面越软，属于正常现象。
  • 变焦是数码裁切，切换前后摄像头会自动回到 1 倍。
  • 录像时变焦同样会写入画面，但镜头切换仍会中断录制。
  • 控制盘和底部面板都可以收起：控制盘收成右侧小圆钮，底部面板缩到屏幕最下方，互不影响，状态会记住。

5.3 点击对焦

在预览画面上轻点一下，白色对焦圈会在点击位置出现，相机同时把对焦和测光区域移到该点：

  • 轻点即可生效；拖动画面（例如抚摸小精灵）不会触发对焦。
  • 对焦圈约 1.5 秒后淡出，对焦 / 测光区域保留到下一次点击。
  • 摄像头不支持区域对焦时轻点不会有反应；部分机型只支持测光点，不支持对焦区域。

6. 风格与强度

点底部「风格 · 当前风格 ▾」打开风格面板，所有风格在一个面板里选，点一下立即生效，点「完成」收起。

风格 特点
正常（默认） 不做任何卡通处理，直接输出相机画面
卡通 平整色块 + 描边，通用卡通感
漫画 更强描边和网点
水彩 柔和色块、轻微颗粒
素描 黑白铅笔线条
像素 像素块化
霓虹 高饱和、发光描边

风格面板下方的「卡通强度」滑块为 0%–100%，只对卡通类风格有效；「正常」下自动置灰。再往下是「同时保存原素材」开关：

  • 打开后，非「正常」风格拍照/录像会各保存两份：一份原素材，一份叠加风格。
  • 「正常」风格只保存一份，不重复占空间。
  • 开关会记忆，下次打开保持不变。

「正常」模式下，预览、录像、拍照、相册处理都原样输出，只保留画面裁剪和前置镜像。

7. 小精灵

  • 默认关闭。点顶部 ✦ 打开，再点关闭；按钮变暗表示关闭。
  • 打开后，小精灵会出现在实时预览、录像、拍照和相册处理结果里；关闭后全部不出现。
  • 小精灵会根据画面内容挑平整的位置落脚，随手机晃动、触摸抚摸、敲击做出不同反应。
  • 目前有 8 个种族、6 种性格，每次出现的小精灵不完全一样。

建议：想要干净的照片就保持关闭；想要“呆瓜”一点的效果再打开。

8. 构图助手

点顶部「构图」开启（按钮变亮），再点关闭。开启后相机每隔约 0.7 秒分析一次当前画面，把建议显示在取景框底部；连续两次给出同一条建议才显示，避免提示乱跳。

画面上会看到

  • 网格：长按「构图」选择三分法 / 中心 / 对角线；三分法四角还有小刻度，方便把主体放在交叉点附近。
  • 主体框：琥珀色框住分析到的主体，构图合适时变绿。
  • 人脸框：检测到人脸时用细白框标出；如果主体就是人，建议会围绕人脸给。
  • 地平线：检测到天空和地面时，用青色线画出地平线，歪了会提示转正。
  • 提示条：画面上方一句主建议，下面一行小字说明依据（主体占比、天空占比、倾斜角等）。带「→ / ← / ↑ / ↓」的提示表示画面该往哪边挪。

会给出的建议

情况 提示
地平线倾斜超过约 2° 把手机转正（人像模式下不提示）
背景明显比主体亮 逆光：点提示条下方的「套用逆光」直接切到「逆光」场景
主体太小 / 太满 靠近一点，或退后一点
头顶贴边 上方留一点空间
主体偏离三分线 往左 / 往右挪一点，并给出方向箭头
背景杂物太多 换个角度避开杂乱边缘
左右对称但没摆正 往对称中心挪一点
有引导线并对齐三分线 提示“引导线用得好”，按快门即可

设置（长按「构图」）

  • 网格：三分法 / 中心 / 对角线。
  • 主体优先：自动 / 人像 / 风光。人像会优先用人脸当主体，风光更关注地平线和整体布局。
  • 自动校平：开启后，拍照时如果地平线歪了 0.6°–8°，会自动旋转并裁切把画面校平（照片尺寸不变，四角不会露黑边）。

说明：构图分析全部在本机用轻量图像算法完成，不上传画面；相机暂时不出帧时会跳过本次分析，不影响正常拍摄。

9. 相册调色

  1. 点快门行左侧的「相册」，选择一张图片或一段视频。
  2. 打开调色编辑器：上方是预览，中间是模式标签，下面是参数滑块。预览区只占一小块，点一下图片即可全屏查看完整画面，点屏幕任意位置关闭。
  3. 调好后点「保存成片」，处理完成会提示保存位置；图片会全屏显示完整画面。

模式（点一下即套用）

模式 效果
原图 不做任何调整
自动优化 自动色阶 + 轻微提饱和，适合曝光平淡的照片
鲜明 提高对比和饱和度
柔和 低对比、低饱和、轻微颗粒
黑白 去色 + 提高对比 + 轻暗角
复古 / 胶片 暖调、低饱和、颗粒与暗角
冷调 / 暖调 整体色温偏移
青橙 轻微色相偏移 + 暗角，电影感
底片转成片 反相并中和橙色底罩，专治底片模式拍的文件

参数滑块

  • 亮度、对比度、饱和度
  • 色温（负值偏冷、正值偏暖）
  • 色觉 / 色相（-180°–+180°）
  • 色差（红蓝通道左右分离，模拟镜头色差）
  • 暗角、颗粒
  • 底片转成片（0%–100%，任何照片都能反相）

保存与复用

  • 点「存为模式」，给当前这组参数起个名字，就会出现在模式标签末尾（带 ·自），以后一键套用；长按自定义模式可删除。
  • 打开文件名带 Daigua_NEG_ 的底片时，会自动选中「底片转成片」。
  • 编辑器里的「卡通化（当前风格）」保留原来的相册卡通化：按当前风格、强度和小精灵开关处理。

处理规则

  • 照片：调色后保存为 JPEG 到 Pictures/DaiguaCamera，文件名为 Daigua_EDIT_…jpg；实时预览最长边约 900，成片最长边 1600。
  • 视频：逐帧调色后重编码为 mp4 到 Movies/DaiguaCamera，原音轨保留；最长边 1280，耗时比照片长。
  • 视频的「自动优化」使用固定增强曲线（逐帧统计直方图代价太高），照片则按整张图自动计算黑白场。
  • 处理视频会调用硬件编解码，机身发热、耗电属于正常现象。

11. 常见问题

预览黑屏 / 相机打不开
检查是否授予相机权限；如果其他应用正在占用相机，先关闭它；仍不行时退出重进。

录像没有声音
麦克风权限被拒绝。到系统设置 → 应用 → 呆瓜相机 → 权限，打开麦克风。

保存失败
Android 9 及以下需要存储权限；同时确认手机剩余空间充足。

拍照处理失败
应用会自动降级重试（关闭小精灵、降低分辨率）；如果相机原图始终拿不到，会改为保存当前预览画面并在弹窗中说明原因。

相册视频处理很久
调色 / 卡通化都需要逐帧解码和重编码。只想保留原片时，在相册编辑器里点「取消」，或使用「卡通化（当前风格）」前把风格切到「正常」并关闭小精灵，会直接复制原视频。

闪光灯不亮
先看顶部 ⚡ 是否是「常闭」；前置摄像头一般没有闪光灯；专业模式手动曝光时「自动」不会闪，请切到「常开」。

双指捏合不能变焦
先在画面右侧的焦距控制盘上试一下：能拖动说明摄像头支持变焦，双指需要在预览画面（不要按在按钮或面板上）操作。前置镜头常常不支持，切到后置再试。

从相册读取不到拍摄参数
微信、微博等应用保存的图片经常抹掉了 EXIF；截图也没有拍摄参数。用相机原生拍摄的照片成功率最高。视频能读到的参数本来就少，读不到的部分会保持自动。

换手机后设置没了
风格、专业参数、场景等设置只保存在本机应用私有空间，卸载或换机不会同步。

想要更干净的画面
风格选「正常」、关闭小精灵；需要更强效果时再提高卡通风格强度。
