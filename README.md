# 呆瓜相机

Android 实时卡通相机：Camera2 + OpenGL ES 预览/录像实时滤镜，支持拍照、相册图片与视频卡通化，以及可互动的小精灵。

- 包名：`com.qoder.daiguacamera`
- 最低系统：Android 7.0（API 24）
- 当前版本：v1.26（versionCode 27）

## 功能

- 7 种风格：正常（默认）、卡通、漫画、水彩、素描、像素、霓虹
- 录像、拍照；两种拍摄方式都含普通 / 专业 / 傻瓜三种模式，内置 38 个场景（含「日常」「自动场景」两个固定预设），覆盖清晨、中午、傍晚、阴天、室内、夜景人像、舞台、宠物、树叶、树、文档等常用光线
- 拍照额外提供**底片模式**：实时负片预览，反转、橙色底罩、对比、饱和、色相、颗粒、亮度可调，成片可在相册一键转正
- 专业参数可调：ISO、快门、曝光补偿、白平衡、对焦、手动焦距；录像快门自动限制在 1/30 秒内
- 场景参数可编辑、可保存、可恢复默认，支持新增自定义场景
- 构图助手：三分法 / 中心 / 对角线网格、主体与人脸框、地平线检测与倾斜提示、三分线偏移方向提示、逆光一键套用场景；可选拍照自动校平
- 从相册照片 / 视频读取 EXIF 拍摄参数并保存为新场景；专业参数也可一键「存为场景」
- 拍照 / 录像保存后不再提示；可选「同时保存原素材」，非正常风格时同时保留原片与风格成品
- 底部深色圆角面板：拍摄方式 / 模式 / 风格与参数三层排列，可一键收起到底部；顶栏精简
- 闪光灯 自动 / 常开 / 常闭（默认自动），录像「常开」为常亮补光
- 变焦：右侧镜头环式焦距控制盘（可收成小圆钮）+ 双指捏合；主摄量程 1×–100×，独立超广角镜头为 0.1×–1×（1× 与主摄衔接），盘面标出常用倍数、可点数字跳转；支持变焦比例的机型可直接到 0.5× 广角；超过设备上限用软件裁切补足
- 应用图标：呆瓜（西瓜）+ 相机镜头
- 点击预览设置对焦点：轻点出现对焦圈，AF / AE 测光区域跟随到点击位置
- 相册调色编辑器（照片 / 视频）：自动优化、11 种内置模式、亮度 / 对比 / 饱和 / 色温 / 色相 / 色差 / 暗角 / 颗粒 / 底片转成片，照片实时预览，自定义模式可保存复用
- 相册图片 / 视频卡通化（编辑器内「卡通化（当前风格）」），视频保留原音轨
- 小精灵默认关闭，可在预览、拍照、相册处理中开启
- 操作手册与版本更新说明内置在 APK 中，顶部「说明」按钮离线查看

## 构建

无需 Gradle，依赖 Android SDK build-tools 与 platform：

```bash
./build.sh
```

脚本依次执行 aapt2 资源编译与链接、javac、d8、APK 重打包、zipalign、apksigner，输出 `daigua-camera.apk`。
